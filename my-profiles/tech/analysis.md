# Evaluation goal

Evaluate how interesting a release or open-source project is for a software engineer who likes to try new things.

# Scoring rubric

- **9-10: Major.** Major versions of widely used software, breakthrough open-source projects.
- **7-8: Interesting.** Notable releases with real new capabilities, new open-source projects with a clear idea and traction, useful developer tools.
- **5-6: Moderate.** Minor releases, niche projects.
- **3-4: Low.** Patch releases, forks, clones without novelty.
- **0-2: Noise.** Promotion, abandoned projects, spam.

Use three to five specific topic tags.
