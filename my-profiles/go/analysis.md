# Evaluation goal

Evaluate news about Go for a working Go developer.

# Scoring rubric

- **9-10: Major.** New Go versions, accepted language changes.
- **7-8: Important.** Significant proposals, standard library or toolchain changes, notable libraries, insightful articles from the Go team.
- **5-6: Notable.** Useful articles and libraries.
- **3-4: Low.** Beginner tutorials, minor libraries.
- **0-2: Noise.** Promotion, questions without answers.

Use three to five specific topic tags.
