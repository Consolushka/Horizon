### [XNU Linux: графическое окружение macOS поверх Linux](https://github.com/AFK-surf/xnulinux) ⭐️ 7.0/10

XNU Linux — открытый проект на GitHub, цель которого — запустить полноценное графическое пользовательское окружение macOS на Linux, используя ядро XNU как компонент системы. Для работы проекту, по отзывам комментаторов, по-прежнему нужно оборудование Apple.

hackernews · mmastrac · Nov 23, 03:49 · [Обсуждение](https://news.ycombinator.com/item?id=50607261)

**「Обсуждение」** По мнению одного из комментаторов, у macOS, как и у Windows, нет стабильного интерфейса системных вызовов, поэтому приложения динамически линкуются с системными библиотеками, и это делает интереснее запуск пользовательского окружения macOS поверх обычного Linux почти без доработки ядра.

**Теги**: `#macos`, `#linux`, `#xnu-kernel`, `#compatibility-layer`, `#os-internals`

### [Cloudflare заменил 2500 MCP-тулов двумя](https://blog.cloudflare.com/code-mode-mcp/) ⭐️ 7.0/10
