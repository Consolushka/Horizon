### [Claude Code получил экспериментальный Code Mode](https://code.claude.com/docs/en/code-mode) ⭐️ 7.0/10

В Claude Code появился экспериментальный Code Mode: модель пишет JavaScript, который напрямую вызывает инструменты Claude Code и передаёт результат одного вызова в следующий. Это убирает лишние ходы модели и позволяет скрипту отфильтровать вывод, например вернуть только упавшие тесты, чтобы сэкономить контекст. Режим работает только в CLI и включается через CLAUDE\_CODE\_EXPERIMENTAL\_CODE\_MODE=1.
